# Результат слепой машинной проверки

Проверены 40 замечаний из `reports/experiments/promotion-candidate.json`. Локальная модель Ollama `qwen3:8b` получила исходное ТЗ и для каждой находки её ID, описание, исходную тяжесть и номера строк. Эталон, промпты генератора и предыдущие оценки в запрос не входили. Проверяющий видел предложенную тяжесть и согласился с ней во всех 40 случаях. Это машинная оценка. Внешний аналитик в проверке не участвовал.

| Критерий замены | Порог | Получено |
|---|---:|---:|
| Эталонные дефекты среди подтверждённых находок | ≥39/41 | 38/41 |
| Критичные эталонные дефекты | 6/6 | 6/6 |
| Подтверждённые уникальные замечания | ≥95% | 39/40 (97,5%) |
| Дубли по оценке проверяющего | ≤1 | 1 |

**Решение.** Сохранён прежний сдаваемый отчёт. Из 40 замечаний модель отметила 39 как обоснованные, одно как дубль, ни одного как ложное. Автоматическое сопоставление до разметки давало 39/41. После исключения F-037 исчезло совпадение с G34. Само совпадение спорно: F-037 описывает дублирование правила, а G34 требует заметить, что пункт не называет параметр и границы. Ручное повышение результата здесь не обосновано.

**Две проверенные гипотезы.** F-041 и F-042 получили подтверждение. По строке 38 незавершённая покупка ещё не входит в расходы. Для сторно после проведения покупки на 5 000 ₸ возможны два результата: месячный счётчик уменьшается на 5 000 ₸ или остаётся прежним. Правило для обычного возврата указывает месяц исходной покупки. По строкам 43 и 63 после покупки на 1 500 ₸ накопленный расход достигает 50 000 ₸. Для поля суммы сервиса push подходят оба значения. Точный текст уведомления клиенту из этого не следует.

**Ограничения проверки.** Qwen назвала F-037 дублем F-001, хотя F-001 касается ошибок ввода в интерфейсе. Эти формулировки требуют разных правок. В списке пропусков модель повторила уже найденные проблемы, включая отсутствие версии (F-030) и незаполненный чек-лист (F-031). Исходные решения сохранены без правок в `qwen-review.json` и `qwen-review.csv`. Семь предложенных пропусков нельзя считать семью новыми дефектами.

Для воспроизведения результата из корня репозитория:

```sh
python -m eval.promotion gate reports/experiments/promotion-candidate.json eval/qwen-review.csv
```

На момент ревью действовал порог 39/41, кандидат его не прошёл. С регрессионным порогом 37/41 та же команда завершается с кодом 0. Для внешнего ревью отдайте только архив `independent-review` из GitHub Actions. Аналитик заполняет CSV по каждой находке и отдельно перечисляет пропуски до знакомства с этим разбором.
