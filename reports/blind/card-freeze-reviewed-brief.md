# Кратко: проверка требований «Временная блокировка карты»

> Итог: разработку начинать — **Нет**, тестирование — **Нет**. Требований: 5, нарушений: 10 (критичных 3, существенных 6, незначительных 1).

**Главное — что исправить до старта разработки:**

🔴 **F-006** (Непротиворечивость, строка 2) — Прямое логическое противоречие: Ф-1 запрещает любые операции оплаты для заблокированной карты, тогда как Ф-2 разрешает офлайн-оплату для той же карты.

🔴 **F-003** (Корректность, строка 4) — Прямое логическое противоречие между требованием Ф-3 и критерием приёмки AC-1.

🔴 **F-005** (Корректность, строка 7) — Противоречие в спецификации API: Ф-5 требует 204 без тела, AC-2 требует 200 с JSON.

🟠 **F-008** (Полнота набора, строка 2) — Не определена обработка операций, которые были инициированы до блокировки, но завершаются после (например, отложенные списания или авторизации).

🟠 **F-009** (Полнота набора, строка 4) — Отсутствует описание жизненного цикла блокировки при возникновении обратных операций или смене настроек в течение 24-часового периода.

🟠 **F-010** (Полнота набора, строка 6) — Отсутствует определение наблюдаемого результата для статуса блокировки: не указан источник данных (API-метод) и формат ответа для фронтенда.

🟠 **F-001** (Трассируемость, строка 2) — Отсутствуют критерии приёмки или ссылки на тест-кейсы для проверки отклонения операций.

Нарушения по критериям: Полнота набора — 3, Трассируемость — 2, Корректность — 2, Однозначность — 1, Непротиворечивость — 1, Модифицируемость — 1.

**Что исправить в первую очередь:**

1. Устранить противоречия в логике блокировки (Ф-1 vs Ф-2) и автоматического снятия (Ф-3 vs AC-1). (F-003, F-006)
2. Привести спецификацию API к единому стандарту (выбор между 204 и 200). (F-005)
3. Дополнить документ описанием обработки транзакций, инициированных до блокировки, и жизненного цикла статуса. (F-008, F-009)
4. Определить технические параметры отображения статуса (API-метод, формат JSON). (F-010)
5. Добавить критерии приёмки для всех сценариев и устранить субъективные формулировки. (F-001, F-002, F-004)
6. Добавить метаданные документа (версия, дата). (F-007)
