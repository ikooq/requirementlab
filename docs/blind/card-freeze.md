# Временная блокировка карты
Ф-1. После блокировки система отклоняет каждую новую операцию оплаты.
Ф-2. Офлайн-оплата заблокированной картой всегда разрешена.
Ф-3. Блокировка автоматически снимается через 24 часа.
AC-1. Через 24 часа карта остаётся заблокированной до ручного снятия.
Ф-4. Приложение быстро показывает статус блокировки.
Ф-5. Успешный запрос блокировки возвращает 204 без тела ответа.
AC-2. При успешной блокировке клиент получает 200 и JSON со статусом.
