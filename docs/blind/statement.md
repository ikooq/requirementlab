# Выгрузка выписки по счёту
Версия 1.0 от 27.11.2026. Владелец — команда интернет-банка.
## Цель и границы
Клиент банка получает выписку по выбранному счёту за произвольный календарный интервал в пределах последних двенадцати месяцев.
Сервис работает только с тенговыми счетами. Все даты и границы суток вычисляются по времени Алматы; обе даты интервала включаются.
## Права и хранение
Ф-1. Выписку вправе получить только владелец счёта. Запрос доверенного представителя отклоняется с HTTP 403.
Ф-2. Владельцу разрешено включать операции сразу нескольких собственных счетов в одну выписку.
Ф-3. После создания готовый файл доступен клиенту ровно 48 часов, затем ссылка возвращает HTTP 410.
Ф-4. Скачивание файла должно работать удобно.
## Контракт создания задания
POST /statements принимает авторизованный запрос. Поле accountId обязательно, содержит один идентификатор счёта; передача массива счетов или повтор поля запрещены.
Поле from — первый день интервала, to — последний день. Максимальная длина интервала составляет 31 календарный день.
В ответ сервис возвращает 202 и идентификатор задания. Повтор с тем же ключом идемпотентности и тем же телом возвращает исходный идентификатор.
Ф-5. Для заказа выписки пользователь выбирает один из двух форматов: PDF или CSV.
Параметр format обязателен. Допускается только PDF; любое другое значение приводит к HTTP 422.
## Получение результата
При готовности сервис возвращает ссылку для скачивания, привязанную к клиенту и заданию. Содержимое файла перечисляет операции в хронологическом порядке.
Ф-6. В архив аудита записываются идентификатор задания, идентификатор клиента, момент создания и результат. Срок хранения архива определяется позднее.
## Критерии приёмки
AC-1. Доверенный представитель с действующей доверенностью запрашивает выписку по счёту доверителя и получает 202.
AC-2. Файл, созданный в понедельник в 10:00, уже недоступен во вторник в 10:01; API возвращает 410.
AC-3. Для своего счёта и интервала от 1 по 31 марта включительно клиент получает готовый PDF.
AC-4. Повтор одинакового запроса с тем же ключом идемпотентности возвращает тот же идентификатор задания.
